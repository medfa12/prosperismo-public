# Prosperismo icon set

User-supplied Prosperismo application artwork imported on 2026-08-02 from
`ps-iOS-ClearDark-1024@1x.png.zip`.

- `ps-iOS-Default-1024@1x.png` and `ps-iOS-Dark-1024@1x.png` are the coloured
  light/dark application variants.
- `ps-iOS-ClearLight-1024@1x.png` and
  `ps-iOS-ClearDark-1024@1x.png` are monochrome variants.
- the cropped SVG files are source elements from the supplied icon package.
- `prosperismo.ico` and the square PNGs are mechanically resized Windows
  deployment assets generated from the dark coloured variant.

These are Prosperismo project assets. They are not extracted PlayStation or
Sony system artwork.
